# Telegram Bot

AI-бот для Telegram с голосовыми сообщениями. Умеет отвечать на вопросы текстом и голосом, распознавать голосовые сообщения и отправлять сообщения в группу.

## Стек технологий

| Компонент | Сервис | Стоимость |
|---|---|---|
| **AI ответы** | OpenRouter (GPT-3.5-turbo) | по тарифу OpenRouter |
| **Распознавание речи** (STT) | Groq Whisper | бесплатно |
| **Озвучка ответов** (TTS) | Microsoft Edge TTS | бесплатно |
| **Фреймворк бота** | Telegraf (Node.js) | бесплатно |

## Возможности

- 💬 **AI-ответы** — отвечает на текстовые сообщения через OpenRouter (GPT-3.5-turbo)
- 🎤 **Распознавание голоса** — распознаёт голосовые сообщения через Groq Whisper
- 🔊 **Голосовые ответы** — отвечает голосовым сообщением через Microsoft Edge TTS
- 📢 **Отправка в группу** — может отправлять сообщения в Telegram-группу
- 🧠 **Контекст диалога** — помнит до 50 последних сообщений каждого пользователя
- ⚙️ **Настройки** — голосовой режим включается/выключается командой

## Команды бота

- `/start` — приветствие и список команд
- `/voice` — включить/выключить голосовые ответы
- `/send <текст>` — отправить сообщение в группу
- `/chatid` — показать ID текущего чата

## Установка

### Требования

- Node.js 18+
- Python 3.9+
- Токен бота от [@BotFather](https://t.me/BotFather)
- API ключ [OpenRouter](https://openrouter.ai)
- API ключ [Groq](https://console.groq.com)

### Шаги

1. Клонируй репозиторий:
```bash
git clone <url>
cd telegram-bot
```

2. Установи зависимости:
```bash
npm install
pip3 install edge-tts
```

3. Создай файл `.env`:
```env
BOT_TOKEN=<токен от BotFather>
ADMIN_CHAT_ID=<твой Telegram user ID>
OPENROUTER_API_KEY=<ключ OpenRouter>
GROQ_API_KEY=<ключ Groq>
```

4. Запусти:
```bash
npm start
```

## Настройка группы

1. Добавь бота в группу
2. Дай ему права администратора
3. Напиши что-нибудь в группе — бот запомнит её ID
4. Теперь можно отправлять сообщения через `/send`

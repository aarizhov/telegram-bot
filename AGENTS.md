# AGENTS.md

## Обзор проекта

Telegram-бот на Node.js с AI-ответами, распознаванием и синтезом речи.

## Стек

- **Runtime:** Node.js 18 (ESM modules, `"type": "module"`)
- **Фреймворк бота:** Telegraf v4
- **AI:** OpenRouter API (GPT-3.5-turbo)
- **STT (речь → текст):** Groq Whisper API
- **TTS (текст → речь):** Microsoft Edge TTS через Python-скрипт `tts.py`
- **HTTP:** axios, form-data

## Структура

- `bot.js` — основной файл бота (точка входа)
- `tts.py` — Python-скрипт для синтеза речи (вызывается из Node.js через child_process)
- `.env` — секреты (BOT_TOKEN, ADMIN_CHAT_ID, OPENROUTER_API_KEY, GROQ_API_KEY)

## Запуск

```bash
npm start
```

Требуется установленный `edge-tts` для Python: `pip3 install edge-tts`

## Команды бота

- `/start` — приветствие и список команд
- `/voice` — вкл/выкл голосовые ответы
- `/setvoice` — выбор голоса через inline-кнопки (Дмитрий, Светлана, Остап, Полина)
- `/send <текст>` — отправить сообщение в группу
- `/chatid` — показать ID чата
- Подсказки команд зарегистрированы через `setMyCommands`

## Доступные голоса TTS

- `ru-RU-DmitryNeural` — мужской, русский (по умолчанию)
- `ru-RU-SvetlanaNeural` — женский, русский
- `uk-UA-OstapNeural` — мужской, украинский
- `uk-UA-PolinaNeural` — женский, украинский
- `ru-RU-DariyaNeural` — НЕ РАБОТАЕТ, не использовать

## Важные детали

- Бот отвечает только в личных сообщениях, в группе только запоминает chat ID
- Контекст диалога хранится в памяти (Map), 50 последних сообщений **на каждого пользователя отдельно**, сбрасывается при перезапуске
- TTS работает через вызов Python из Node.js (stdin → файл → Buffer), потому что Node-пакеты для Edge TTS нестабильны на Node 18
- TTS таймаут: 60 сек, текст обрезается до 1000 символов, retry 3 попытки с паузой 2 сек
- TTS подвержен rate-limiting от Microsoft — при частых запросах может возвращать ошибку
- Голосовые ответы включены по умолчанию, переключаются командой `/voice`
- Выбор голоса реализован через inline-кнопки (callback_data)
- Group chat ID захардкожен как fallback: `-5157172835`
- При запуске отправляет "Бот запущен!" админу в личку
